# 하루 박자 · 맛보기 v0

1주차 1일, 신생아 아빠의 네 가지 리듬 놀이. `index.html`을 브라우저로 바로 여세요. 빌드, 서버, 외부 라이브러리, 폰트, 이미지, 네트워크 요청이 없습니다. 파일을 함께 두어야 합니다.

## 조작과 흐름

- 시작 버튼으로 오디오를 활성화합니다. 아이폰은 기기의 음량과 무음 설정도 확인하세요.
- 아침: “슝—”을 듣고 다음 박에 탭. 두 번 신호에는 반 박 간격으로 두 번 탭합니다. 신생아의 이유식은 화면에 표시한 상상 놀이입니다.
- 출근: 초록 손잡이 버튼을 길게 누르고, 주황 도장 버튼으로 서류를 처리합니다. 두 손가락 또는 마우스 유지 + 엔터를 사용할 수 있습니다. 키보드는 스페이스 유지 + 엔터입니다. 홀드 끝까지 유지하면 자동 완료됩니다.
- 연구실: 세 박의 콜을 듣고 바로 다음 세 박에 응답합니다. 그래프 위쪽은 이른 입력, 아래쪽은 늦은 입력입니다. 미스는 아래쪽 점으로 남습니다.
- 밤: 3박자 중 첫 박에 토닥입니다. 후반에는 반주와 목표 박자가 함께 느려집니다.
- 기본 입력은 버튼 터치, 클릭, 스페이스 또는 엔터입니다. 반복 키 입력은 무시합니다. 소리 OFF 버튼은 전체 음향을 끕니다.
- 각 게임에 점수 없는 약 4초 연습이 있고 본 곡은 약 48~51초입니다. 게임 사이에는 1.6초 전환이 있습니다.
- 화면을 벗어나거나 쉬기 버튼을 누르면 중단합니다. 돌아오면 현재 게임의 컨디션 변화를 되돌리고 연습부터 재시작합니다.

보정 화면에서 4박을 듣고 8박에 맞춰 누르면 평균 오프셋이 저장됩니다(6박 이상 필요). 슬라이더로 ±250ms 범위에서 직접 수정할 수도 있습니다. 양수는 늦은 입력을 앞당깁니다. 저장은 `localStorage`를 try/catch로 감싸며, 저장이 차단된 환경에서도 현재 실행에는 적용됩니다. 파일 URL에서 저장 정책은 브라우저마다 다릅니다.

## 구조와 타이밍

- `index.html`: 한국어 화면, 조작 버튼, Canvas, 결과 그래프.
- `style.css`: 파스텔 화면과 세로 모바일 / 중앙 정렬 PC 레이아웃.
- `core.js`: DOM 없는 판정, 컨디션, 점수, BPM, 절대 박자 타임라인과 패턴 생성. 일반 script와 Node 모두에서 사용됩니다.
- `app.js`: Web Audio 합성, 상태 전환, 입력, 보정, Canvas 렌더링.
- `tests/run.mjs`, `tests/runtime.mjs`: 순수 계산 및 가상 DOM/오디오 통합 테스트.

박자는 `AudioContext.currentTime`에서 시작 시점을 얻고 절대 박자 인덱스로 계산합니다. 20ms 타이머가 150ms 앞까지 오실레이터와 노이즈를 예약합니다. 타이머 횟수를 더해 곡의 시간을 만들지 않습니다. `requestAnimationFrame`은 오디오 시각을 읽어 그림과 표시만 갱신합니다. 밤 곡은 후반 각 박 간격을 선형으로 늘린 합을 절대 시각으로 계산합니다. 각 곡은 별도의 베이스, 멜로디, 드럼/타악 패턴을 사용하며 신호음을 구분했습니다.

판정은 오프셋을 뺀 입력 시각과 목표 시각의 차이입니다. 기본 퍼펙트 ±45ms, 굿 ±90ms이며 컨디션 35 미만은 두 창을 86%로 줄입니다. 컨디션은 퍼펙트 +1.1, 굿 +0.15, 미스 −3.1로 0~100 안에서 변합니다. 다음 곡 시작 시 컨디션 60 미만이면 BPM을 최대 7.2 올리고, 35 미만이면 화면이 작게 떨립니다. 홀드는 시작 판정과 유지 여부를 합쳐 1개 결과로 기록합니다. 연습은 점수와 컨디션에 영향을 주지 않습니다.

연구/평가는 해당 곡 판정의 평균(퍼펙트 100, 굿 65, 미스 0), 아기는 아침과 밤의 모든 판정을 합산한 평균입니다. 컨디션 그래프는 하루 시작과 각 곡 완료 시점의 다섯 값을 표시합니다.

## 미니게임 / 다음 날 추가

1. `app.js`의 `games`에 제목, 시간대, BPM, 안내, 버튼 이름을 추가합니다.
2. `core.js`의 `makeChart`에 박자 인덱스로 입력 목표를 추가합니다. 홀드는 `type: 'hold'`와 종료 박자, 도장은 `type: 'stamp'`를 씁니다. 일반 탭은 `tap`입니다.
3. `app.js`의 `music`, `cue`, 연습 패턴, `draw`에 해당 곡과 장면을 연결합니다. 오디오 예약은 `run.queue`에 `{t, fn}`으로 추가합니다. 렌더러에서 소리를 재생하지 마세요.
4. 점수 막대 배분과 결과 문구를 `results`에 연결하고 타임라인·입력 테스트를 추가합니다.

현재는 확정된 하루를 위한 인덱스 0~3 구현입니다. 다음 4일을 추가할 때는 일별 `games`/점수 배분/아기 단계 설정으로 먼저 분리한 다음 같은 엔진을 재사용하는 것이 좋습니다. 음악/씬 분기도 각 게임 정의의 함수로 옮길 수 있습니다.

## 검증

```sh
node tests/run.mjs
node --check app.js
```

판정 경계, 컨디션 범위, 점수, 60초 누적 오차, 곡 길이, 엇박·홀드·콜앤리스폰스, 리타르단도, 보정 평균을 검증합니다. 가상 오디오 시계로 네 곡 전체를 진행하고 모든 Canvas 분기, 3막대 100점, 연습 제외, 홀드와 도장 동시 입력, 중단 시 컨디션 복원, 8박 보정도 확인합니다.

가상 환경 테스트는 실제 스피커 지연과 터치 감각을 검증하지 않습니다. 실제 아이폰 Safari와 PC 브라우저에서 음량, 두 손가락 홀드/도장, 백그라운드 복귀, 보정, 작은 화면을 확인해야 합니다. 오디오 기능이 없는 브라우저는 시작 시 안내합니다. 네트워크 접속 및 git push를 하지 않았습니다.
